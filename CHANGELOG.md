# Changelog

All notable changes to the EduInsight AI project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0-foundation] - 2026-11-01

### Added
- Complete enterprise master folder structure across 10 project development phases.
- React 18 + Vite frontend architecture with full JSX components, Material UI, Lucide icons, and Recharts.
- Node.js + Express backend with ES Modules (`type: module`), security middleware, and modular layered routing.
- Neon PostgreSQL database architecture with 22 relational tables, schema migrations, seeds, views, and functions.
- AI Engine directory structure with prompt templates, analytics calculators, validators, and service contracts.
- Complete documentation suite (project, architecture, database ERD, API specs, security policies, phase guides).
- Comprehensive automated structure validation script (`scripts/validate-structure.js`).
- GitHub Actions CI/CD workflows for frontend and backend validation.
- Standard project submission materials (viva guide, project report sections, presentation slides, architecture diagrams).
