# Coding Standards & Conventions

1. **Strict Language Rule**: JavaScript ES6+ and React JSX only. NO TypeScript allowed.
2. **File Extensions**:
   - React components: `.jsx`
   - Pure modules & services: `.js`
   - Database migrations: `.sql`
3. **Layering Rule**:
   `Routes -> Controllers -> Services -> Repositories -> Database`
4. **Style Guide**:
   - Single quotes, 2 spaces indentation, trailing commas for ES5, semicolons required.
   - Run `npm run lint` before committing code.
