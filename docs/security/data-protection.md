# Data Protection & Privacy Policy

- **Student Record Confidentiality**: Students are strictly prohibited from viewing grades, attendance, or AI predictions belonging to any peer.
- **AI Privacy Fence**: Student names, contact emails, and personal phones are stripped before submitting metrics to the OpenAI API.
- **SQL Parameterization**: 100% of SQL statements across all repositories use bound parameter arrays (`$1`, `$2`) to eliminate SQL injection vectors.
