# Frontend Architecture

- **Modular Feature Design**: Organized by domain under `client/src/features/` (`auth`, `admin`, `faculty`, `student`, `analytics`, `ai-insights`, `ai-assistant`).
- **Strict JavaScript + JSX**: Pure JSX components without TypeScript.
- **Design System**: Material UI v5 engine customized with a clean light academic palette and Lucide React icons.
- **State Management**: React Context API for authentication, theme preferences, notifications, and active filters.
- **Visualization**: Recharts responsive container library for high-performance SVG line, bar, pie, and area charts.
