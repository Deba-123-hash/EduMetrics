# Centralized Testing Suite

This directory contains enterprise-grade testing suites across all test tiers:

- `unit/`: Granular logic testing for independent calculators and helpers.
- `integration/`: Multi-component testing for Express endpoints with PostgreSQL.
- `end-to-end/`: Complete browser workflow automation using Playwright.
- `performance/`: Load testing scenarios measuring API latency under concurrent requests.
- `security/`: Automated vulnerability scans checking for OWASP Top 10 vectors.
