# Slide-by-Slide Content Deck

### Slide 1: Title
**EduInsight AI**  
*AI-Powered Student Performance Analytics and Prediction Dashboard*  
Master of Computer Applications (MCA) Final-Year Major Project

### Slide 2: The Challenge
- Fragmented records across departments.
- Manual grade calculations prone to clerical error.
- Late interventions after students have already failed semester exams.

### Slide 3: The EduInsight AI Solution
- Unified, automated student record platform.
- Real-time attendance compliance monitoring.
- Explainable, mathematical composite risk scoring.
- Grounded AI assistant for rapid institutional queries.

### Slide 4: Strict Technical Stack
- **Frontend**: React 18, Vite, Material UI, Recharts, Lucide Icons. Pure JSX.
- **Backend**: Node.js, Express, ES Modules, Zod, Helmet.
- **Database**: Neon Serverless PostgreSQL with pg connection pooling.
- **AI**: OpenAI API with deterministic temperature and strict JSON validation.
