# MCA Major Project Viva Examination - Key Questions

1. **Architecture**: Why did you choose a layered architecture (`Route -> Controller -> Service -> Repository -> Database`) over putting logic in route handlers?
2. **Database**: Why use PostgreSQL instead of MongoDB for this application?
3. **Primary Keys**: What are the advantages and trade-offs of using UUIDs instead of auto-incrementing integers?
4. **Security**: How do you prevent SQL injection and authentication token theft?
5. **AI Reliability**: How does your system ensure the AI does not hallucinate student marks or attendance percentages?
6. **State Management**: Why use React Context API instead of Redux?
7. **Concurrency**: How does your system handle simultaneous marks entry by multiple faculty members?
